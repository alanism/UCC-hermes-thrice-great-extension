# California Common Core ELA — Grade 11

> Reference benchmark only. Benchmarks inform. They do not command.

This grade-equivalence view contains 19 PI/PII benchmark nodes. ELA capabilities spiral across grades; this page is reference terrain rather than a fixed learning path.
