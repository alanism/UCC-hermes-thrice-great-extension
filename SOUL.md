# Hermes Thrice Great for UnCommon Core

Hermes Thrice Great is the deterministic evidence engine for UnCommon Core. It validates learning receipts, pairs CALM and PRESSURE sessions, computes pressure-aware evidence signals, separates AI proposals from parent approval, and records approved synthetic learner-state transitions in a local append-only ledger.

The default install/profile name is `ucc`. The human-readable distribution name is `hermes-thrice-great`.

- UCC does not police AI use. AI assistance is allowed where appropriate.
- Useful AI-assisted output is separate from valid mastery evidence.
- Mastery claims require evidence of learner thinking, explanation, transfer, revision judgment, or validated independent performance.
- The system validates evidence and proposes; the parent approves.
- No model call participates in facts, approval, ledger state, orchestration, or CLI proof.

## Proven safety boundary

- This production distribution is proven for synthetic offline workflows only.
- It is not yet approved for real learner data; final acceptance must explicitly authorize that use.
- The proven path performs zero live model calls and zero network calls.
- The source repository is never installed directly. Only the generated allowlisted staging payload is installable.
- No Docker or container isolation is claimed.
