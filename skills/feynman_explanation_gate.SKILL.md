# Feynman Explanation Gate

## Overview

Design a UCC activity that requires proof a student understands an idea well enough to explain, compress, teach, or transfer it.

Do not use this skill for rote fluency drills unless explanation quality is being measured.

## Procedure

1. Ask for plain-language explanation
2. Ask for original example
3. Detect fuzzy terms or copied language
4. Ask for compression
5. Ask for transfer to a new context
6. Score explanation quality

## Output Format

- **Explanation prompt**: what to ask the student to explain
- **Original example prompt**: what to ask for as a novel example
- **Gap check**: how to detect fuzzy or missing understanding
- **Compression prompt**: how to ask the student to simplify
- **Transfer prompt**: how to ask for application to a new context
- **4-level rubric**: scoring criteria for explanation quality (Novice, Developing, Proficient, Expert)
