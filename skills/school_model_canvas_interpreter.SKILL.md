# School Model Canvas Interpreter

## Overview

Translate a family's School Model Canvas into a UCC operating plan, app recommendations, or parent-facing strategy playbook.

Do not use this skill for app QA or mastery ledger design.

## Procedure

1. Extract educational vision
2. Extract child context
3. Extract parent expectations
4. Extract constraints
5. Map to daily/weekly rhythm
6. Recommend UCC tools
7. Define measurement plan

## Output Format

- **Family thesis**: one-sentence educational philosophy
- **Learner profile**: the child's learning style, strengths, and gaps
- **Constraints**: time, resources, parent bandwidth, special needs
- **Weekly rhythm**: recommended daily and weekly schedule
- **Recommended tools**: which UCC apps and activities fit
- **Parent role**: what the parent does day-to-day
- **Measurement plan**: how progress is tracked
- **Risks**: what could go wrong and how to mitigate
