# Mastery Ledger Contract

## Overview

Define what must be stored in the mastery ledger, session receipt, assessment export, or parent dashboard.

Do not use this skill for writing lessons or generating practice problems.

## Procedure

1. Separate practice, mastery, transfer, retention, and assessment
2. Define mastery evidence
3. Define telemetry fields
4. Define error taxonomy
5. Define advancement rules
6. Define parent-facing interpretation

## Output Format

- **Learning function**: which of the 5 functions this ledger entry serves
- **Mastery evidence**: what proves the student has mastered this skill
- **Telemetry fields**: every field the system must record
- **Error taxonomy**: how errors are classified
- **Advancement rule**: conditions for moving to the next skill
- **Retention rule**: conditions for keeping the skill in long-term memory
- **Parent interpretation**: plain-language explanation of what this entry means
