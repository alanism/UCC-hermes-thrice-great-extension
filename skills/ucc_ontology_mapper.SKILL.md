# UCC Ontology Mapper

## Overview

Map UCC concepts, apps, lessons, assessments, telemetry, or parent reports into a knowledge graph or ontology.

Do not use this skill for general pedagogy critique unless entity and relationship design is the main task.

## Procedure

1. Identify entity types
2. Define relationships
3. Define required fields
4. Label evidence types
5. Identify missing links
6. Produce ontology table and acceptance criteria

## Output Format

- **Entities**: list of entity types with descriptions
- **Relationships**: entity pairs with relationship labels
- **Required fields**: per-entity field requirements
- **Evidence labels**: what count as evidence for each relationship
- **Missing links**: gaps in the current graph
- **Acceptance criteria**: conditions for a complete ontology
